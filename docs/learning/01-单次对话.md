# 第一步：调用大模型完成单次对话

这一阶段只验证一条最小链路：

```text
用户输入 → Rust CLI → Chat Completions API → 输出回复
```

当前实现不包含工具调用、上下文记忆、流式输出、数据库和图形界面。

## 配置

复制示例配置：

```powershell
Copy-Item config/example.toml config/local.toml
```

编辑 `config/local.toml`，填写：

- `base_url`：OpenAI-compatible API 的服务地址，例如 `https://api.openai.com/v1`。
- `api_key`：本地 API Key。不要提交到 Git。
- `model`：服务商提供的模型名。

## 运行

```powershell
cargo run
```

在 `You:` 后输入一行消息，程序会发起一次非流式请求并打印 `Assistant` 回复。

## 这一步要理解的代码

- `Config`：从 TOML 文件读取模型服务配置。
- `Message`：当前对话消息的数据结构。
- `ChatRequest`：发送给模型的请求。
- `ChatResponse`：从响应中提取第一条模型回复。
- `call_model`：完成一次 HTTP 调用，不负责会话记忆或工具执行。
