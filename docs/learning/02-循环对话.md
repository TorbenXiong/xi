# 第二步：循环调用和多轮对话

这一阶段把单次调用改成循环：

```text
读取用户输入
  → 把 user 消息加入历史
  → 把完整历史发送给模型
  → 把 assistant 回复加入历史
  → 继续读取下一轮输入
```

## 运行

```powershell
cargo run
```

示例：

```text
You: 我叫小明
Assistant: 你好，小明！

You: 我叫什么？
Assistant: 你叫小明。

You: /exit
会话结束。已保留 4 条消息。
```

输入 `/exit` 或 `/quit` 结束会话。直接发送 EOF 也会结束会话。

## 关键变化

- `main` 中增加 `loop`，持续处理多轮输入。
- `messages` 保存完整会话历史。
- 每次请求都把 `messages` 传给模型。
- 模型回复也会以 `assistant` 消息加入历史。

当前历史会保存到本地 SQLite 数据库，程序重启后会恢复最近使用的分组和会话。可以通过 /groups、/group-new、/group-use、/group-move、/new、/sessions、/use、/rename、/clear、/archive 和 /export 管理数据。

消息和模型请求还会记录状态：成功回复保存为 complete，模型调用失败保存为 failed；程序重启时遗留的流式消息会标记为 interrupted。流式输出期间只在内存累积内容，完成或失败时再写入数据库。
