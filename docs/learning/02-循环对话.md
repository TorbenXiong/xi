# 第二步：循环调用和多轮对话

这一阶段把单次调用改成循环：

```text
读取用户输入
  → 把 user 消息加入历史
  → 把完整历史发送给模型
  → 把 assistant 回复加入历史
  → 继续读取下一轮输入
```

## 运行

```powershell
cargo run --offline --locked -- --cli
```

示例：

```text
You: 我叫小明
Assistant: 你好，小明！

You: 我叫什么？
Assistant: 你叫小明。

You: /exit
会话结束，消息已保存到 SQLite。
```

输入 `/exit` 结束会话。直接发送 EOF 也会结束会话。

## 关键变化

- `src/cli.rs` 的 `run` 使用 `loop`，持续处理多轮输入和管理命令。
- `AppServer::chat` 读取目标会话历史，并在调用模型前保存用户消息。
- `ModelRuntime::complete_with` 把完整的有效历史传给模型；失败或中断的 assistant 消息不进入下一轮上下文。
- 模型回复以 `assistant` 消息加入历史，再写入 SQLite。

最初的 CLI 把 `messages` 保存在进程内存中，退出后丢失。当前 CLI 使用与 UI 相同的 `AppServer`：首条消息创建会话，后续输入使用明确的会话与 Provider ID，历史持久化到 SQLite。默认选择当前服务模型缓存第一项，可用 `/model` 切换、`/reasoning` 设置该模型支持的推理选项。

桌面端和 CLI 共享同一套关系表及运行状态，在模型调用前持久化用户输入。CLI 提供目录项目、移动、归档、搜索和导出命令，详见 [03-项目会话与持久化](03-项目会话与持久化.md)和 [04-应用端架构与调试](04-应用端架构与调试.md)。
