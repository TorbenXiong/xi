# 项目审查与目录项目改造（2026-10-29）

审查覆盖文档、React、HTTP、AppServer、模型调用、SQLite、CLI 和 Tauri。修改位于 fix/project-review，尚未提交。本轮按用户确认改为目录项目，并删除历史配置、旧接口与数据库迁移代码；旧库不迁移，应使用空数据目录。

## 本轮行为

- 项目绑定真实绝对目录，路径规范化、去重；同目录归档后重新打开恢复。名称可留空或与其他目录重名。
- 输入框上方增加项目选择器，支持按名称/路径搜索、创建项目和切换到独立聊天；已有会话切换项目时通过移动接口更新归属。
- 独立会话使用可空 project_id。移除项目保留会话及目录文件，归档隐藏项目及其会话。
- 服务选择从侧栏移到输入区模型左边，排列为服务、模型、推理。
- 推理档位来自服务声明、精确型号预设或逐模型自定义。未知能力不覆盖服务默认；切服务/模型后重置，后端发送前再次校验。
- 桌面默认居中，提供独立设置页、分类搜索、发送快捷键与外观偏好。
- 删除旧分组路由、隐式目标回退、旧配置导入、JSON 快照迁移、系统分组、旧模型字段和全局默认推理项。
- 经用户确认移除未使用的 toml 依赖及无用传递依赖，离线更新根 Cargo.lock，其他锁定版本保留。
- Windows 使用现有系统 API 选择目录，无新增依赖；非 Windows 和 Web 手动输入。
- 桌面验收发现创建项目后可能因刷新前的闭包列表丢失项目选择，已修正：显式创建结果直接作为新会话项目，默认偏好仍校验当前列表。复验确认创建后自动进入该项目。

## 审查修复

| 问题 | 处理 |
| --- | --- |
| 请求头结束符与超限数据同块到达可绕过限制 | 检查实际头部长度，测试边界与请求体随头部到达 |
| 畸形 HTTP 请求直接断开，前端只见网络错误 | 返回 400 与 JSON error，拒绝畸形请求及歧义长度 |
| 空白 Runtime Token | 启动时拒绝，未指定时随机生成 |
| 模型缓存残留下架型号 | 事务整体替换，保留同模型的自定义能力 |
| 编辑中凭据获取模型提前污染已保存缓存 | 仅凭据一致时更新，未保存预览留在表单 |
| 不合法 API 地址可保存 | 保存和调用前验证协议、主机及地址组成 |
| 搜索通配符扩大匹配范围 | 按字面转义百分号、下划线与反斜杠 |
| 多窗口因默认选择改变写入其他会话/服务 | 业务请求明确目标，未知 ID 报错 |
| HTML 或 JSON null 错误响应丢失状态 | 保留 HTTP 状态并报告协议错误 |
| 空失败回复被过滤 | 展示完整 history 状态与错误 |
| 草稿串会话或发送失败丢失输入 | 按会话保留当前窗口草稿，失败恢复 |
| 历史加载失败后仍可向空白视图发送 | 提供重试并禁用发送，过滤迟到响应 |

## 桌面验收

通过 Computer Use 操作实际 Tauri 窗口，使用新的独立 XI_DATA_DIR 和本机模拟服务，没有调用真实模型或读取旧密钥：

- 窗口在工作区居中打开。
- 系统文件夹选择器可打开、取消，并将选中的现存路径回填表单。
- 创建目录项目后正确选中项目，侧栏与输入区目录一致。
- 设置页获取模型、展示能力来源，编辑逗号分隔推理值后保存成功。
- 输入区服务位于模型左侧。
- GPT 菜单展示五档，DeepSeek 展示三档，未知模型显示服务默认；切模型后恢复默认。
- 实际发送一次项目会话，模拟服务收到 deepseek-flash 与 max，回复保存，侧栏会话归属正确。
- 删除验收会话经确认后恢复草稿，项目文件保留。

用户已允许删除旧数据库和密钥，但自动执行策略拒绝数据库文件清理，仅返回 blocked by policy。因此旧数据未清除，验收改用新的独立目录，不能声称默认数据目录已经重置。
